Evidence semantics
------------------
MADV_HUGEPAGE is VMA eligibility, not backing proof.
Process THP backing is measured with /proc/self/smaps_rollup AnonHugePages.
/proc/vmstat THP deltas are system-wide corroboration only.
Formal THP and ordinary-no-THP arms require host THP mode madvise and parseable smaps.
Eager THP requires at least 95% steady backing across THP VMAs.
Epoch THP requires at least 95% steady backing across point-in-time collapse-confirmed extents; sparse candidates deliberately skipped by the 50% occupancy policy remain a separate VMA-coverage result.
Effective resident memory is VmRSS + HugetlbPages, sampled at initial peak, post-first-epoch, every live wave peak, and steady state.
Allocator lifecycle includes the first synchronous epoch promotion and excludes /proc evidence-read time.

Boundary
--------
This is a synthetic, paired allocator microbenchmark with injected classification errors and confidence. It demonstrates mechanism feasibility on one host and one 4 KiB size class. It is not claim-grade application evidence. The host carried unrelated background work; process pinning, randomized case order, paired seeds, and bootstrap intervals bound but do not remove that noise.
