# Real-Program Rust Lifetime-Prior Evidence

This package retains the compact evidence used for the lifetime-prior and
selective-THP presentation figures. The raw campaigns remain under
`evaluation/raw/` and are intentionally excluded from Git. `summary.json`
preserves their source paths and SHA-256 identities, the six Stage-A target
rows, all twenty fixed-work Polars Stage-B samples, and all ten SWC diagnostic
Stage-B samples.

## Result boundary

- SWC Stage A is the strongest classifier result: 96.15% decisive-outcome
  precision, 96.31% decisive-byte precision, and 93.16% Long-byte recall.
- Polars Stage B used four balanced fixed-work repeats. Compiler priors improved
  the paired median over runtime-only ordinary placement by 0.889%, while the
  four per-repeat effects ranged from -0.246% to +1.797%. The same priors had
  zero production-clock Long true positives and 132 Short contradictions per
  run. This is a small timing observation, not evidence of successful Long
  placement.
- Polars produced zero Long routes, zero THP extents, and zero resident
  `AnonHugePages` in both selective-policy arms. Every THP causal comparison is
  blocked; the measured endpoints remain available as policy-arm observations.
- SWC's two-repeat Criterion diagnostic routed about 327,000 runtime-only and
  339,000 compiler-prior Long allocations per sample. Its selective-THP arms
  created 42 THP extents and reached 12 MiB of process-level resident THP.
  Every timed-phase smaps sample was backed after the explicit five-second
  warm-up. Compiler priors were about 98.06% accurate under the production
  clock.
- On SWC, selective THP improved the diagnostic median by 0.882% over
  runtime-only ordinary placement, and compiler priors added 0.667% over the
  runtime-only THP arm. Runtime-policy overhead left the full stack 0.486%
  slower than allocator default. THP increased median peak RSS by 28.30% versus
  runtime-only ordinary placement.

The SWC Stage-B values are diagnostic because Criterion controls the work and
the campaign has two repeats. Polars is the fixed-work performance target.
Stage A uses forced tracking and a process-wide requested-generation clock;
Stage B uses the production eligible-site payload-capacity clock. Process-level
`AnonHugePages` is correlated with positive UniAlloc routing and advice
counters; allocator-VMA residency attribution remains unmeasured.

The modern external TCMalloc baseline is a separate campaign at compatibility
pin `12f255231938d30493186b0a037feedd70f5a1c1`. This package contains no
gperftools substitution and makes no cross-family timing ranking.

## Reproduce the figures

The ignored raw source files must be present at the repository-relative paths
recorded in `summary.json`. The renderer verifies every source digest before it
creates output.

```sh
uv run python evaluation/scripts/render_lifetime_prior_real_program_charts.py \
  --repo-root . \
  --summary docs/evidence/lifetime-prior-real-program-20260715/summary.json \
  --output-dir docs/figures/lifetime-prior-real-program-20260715
```

The SVG and CSV files are canonical. PNG files are optional presentation
conveniences generated by the locally installed ImageMagick version.
